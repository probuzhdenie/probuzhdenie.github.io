# esvetvisit

Сайт храма публикуется из репозитория `probuzhdenie/probuzhdenie.github.io`. Пуш в `main` заново собирает страницу и выкладывает её на https://probuzhdenie.github.io/.

Текущий выпуск — пара файлов `public/data/issue.json` и `public/data/issue.jpg`. Их записывает Telegram-бот из папки `bot/`. На сайте фото доступно как `data/issue.jpg`: Vite копирует содержимое `public/` в корень сборки.

## Бот выпуска

Компьютер для бота не нужен. GitHub Action `.github/workflows/telegram-poll.yml` каждые 5 минут проверяет Telegram. Если редактор прислал новый выпуск, Action записывает `public/data/issue.json` и `public/data/issue.jpg`, коммитит их в `main` и заново публикует сайт. Пока новых сообщений нет, сборка не запускается.

В настройках репозитория `probuzhdenie/probuzhdenie.github.io` добавьте секрет `TELEGRAM_BOT_TOKEN` (Settings → Secrets and variables → Actions). Необязательная переменная `TELEGRAM_ALLOWED_CHAT_IDS` ограничивает чаты, из которых принимается выпуск. Без неё сообщение примет любой чат.

GitHub иногда запускает расписание на несколько минут позже. Фото можно прислать вместе с текстом или следующим сообщением в течение 30 минут. Номер последнего проверенного сообщения хранится в `bot/state.json`, чтобы одно и то же сообщение не публиковалось дважды.

Формат сообщения — обычный текст и одно фото. Отправляйте снимок как фото, не как файл.

```text
Заголовок: ...
Тема: ...
Текст: ...
```

Текст может занимать несколько строк до конца сообщения. Каждый новый выпуск перезаписывает те же два файла.

Локальный запуск тем же кодом, если нужно проверить бота у себя: Node.js 18 или новее, отдельные пакеты не нужны.

```bash
cd bot
set TELEGRAM_BOT_TOKEN=your-bot-token
set GITHUB_TOKEN=github-token-with-contents-write
npm start
```

По умолчанию бот пишет в `probuzhdenie/probuzhdenie.github.io`, ветка `main`. Другой репозиторий задаётся переменной `GITHUB_REPO`.

Токен GitHub — fine-grained, только этот репозиторий, право Contents: Read and write. Секреты читаются из окружения. Не коммитьте их.

В группе режим приватности BotFather скрывает обычные сообщения. Отключите его через `/setprivacy` или пишите боту в личный чат.

`/chatid` отвечает идентификатором чата для `TELEGRAM_ALLOWED_CHAT_IDS`. Если переменная пустая, бот принимает выпуск из любого чата.

Формат сообщения — обычный текст и одно фото. Фото можно прикрепить к тому же сообщению или прислать следующим в течение трёх минут. Отправляйте его как фото, не как файл.

```text
тема: ...
заголовок: ...
колонка1: ...
колонка2: ...
колонка3: ...
```

Колонка может занимать несколько строк до следующей метки. Бот отвечает ссылками на коммиты. Каждый новый выпуск перезаписывает те же два файла: сначала фото, затем JSON.
